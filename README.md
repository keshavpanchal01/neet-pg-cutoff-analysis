# NEET PG 2026 – Round 1 Cutoff Rank Analysis

An interactive, data-driven website for exploring NEET PG 2026 Round 1 allotment results and understanding cutoff ranks across medical specialities.

## Project Overview
Built to make official counselling data more accessible, searchable, and actionable for NEET PG aspirants.

## Data Pipeline
1. **Source:** NEET PG Round 1 official allotment PDF.
2. **Extraction:** Converted allotment data from PDF into structured CSV format.
3. **Development:** Used Claude AI to build an interactive web interface for analysing speciality-wise cutoff ranks.
4. **Deployment:** Published the website using Cloudflare.
5. **Analytics:** Integrated Google Analytics 4 (GA4) to monitor real-world website traffic and usage.

## Tech Stack
- **Data:** PDF, CSV, Excel
- **AI-assisted development:** Claude
- **Frontend:** HTML, CSS, JavaScript
- **Hosting:** Cloudflare
- **Analytics:** Google Analytics 4
